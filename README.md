# ESP32 3D Lab & Studio

Plataforma Web 3D para visualização física, banco de dados de módulos/sensores, guia de fiação e simulador de ESP32 e ESP8266.

## 🚀 Recursos
- **Visualizador 3D Interativo (Three.js WebGL):** Placa ESP32 detalhada, protoboard, módulos e fios jumpers curvos tridimensionais.
- **Banco de Dados de Módulos:** Cadastro de sensores, atuadores, displays e pinagens com persistência no navegador.
- **Guia Físico no Mundo Real:** Tabela com passo a passo pino a pino e cores dos fios jumpers.
- **Testador Virtual:** Controle de alimentação, acionamento do relé, LED onboard GPIO 2 e monitor OLED com simulador de sensor.
- **Gerador de Código:** Código pronto em C++ / Arduino para gravação direta via Arduino IDE.
- **100% Custo Zero Permanente:** Roda diretamente no GitHub Pages.
